# FireSignals Changelog

## 21.0.0-rc.0

### Major Changes

- Rearchitected the RxFire fork as FireSignals.
- Renamed the package to `@zwiqler94/fire-signals`.
- Replaced the public Observable API with Angular signal-first `FireSignal<T>`
  state objects.
- Updated the baseline to Angular 21 and Firebase 12.
- Replaced Jest with Vitest for new tests.

## Upstream History

FireSignals preserves Apache-2.0 attribution for upstream RxFire work. See the
original RxFire project history for pre-fork release notes.
